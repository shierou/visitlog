# 다녀왔어요 — 공유 계정 초대 가이드

Instagram 에서 본 맛집·카페 릴스를 DM 으로 보내면 자동으로 목록에 쌓이는 앱이다.
새로운 사람을 이 앱에 연결하려면 **관리자 등록 → 본인 수락** 두 단계가 필요하다.

Meta 정책상 앱에 등록된 계정이 보낸 DM 만 서버로 전달되기 때문에,
초대 없이 그냥 DM 을 보내면 아무 일도 일어나지 않는다.

---

## A. 관리자가 할 일

Meta 개발자 대시보드에서 상대방 계정을 등록한다. 1~2분이면 끝난다.

1. <https://developers.facebook.com/apps> → **Visitlog Collector** 선택
2. 왼쪽 메뉴 **앱 역할 → 역할**
3. 우측 상단 **「사람 추가」**
4. **"이 앱의 추가 역할"** 에서 **Instagram 테스터** 선택
5. 상대방의 Instagram **사용자명**(@ 없이) 입력 후 추가

목록에 이름이 뜨면 초대가 발송된 것이다. **아직 효력은 없다** — 상대방이
아래 B 를 마쳐야 한다. 대시보드의 `상태` 칸으로는 수락 여부를 알 수 없으니,
상대방에게 직접 확인받는 편이 빠르다.

등록이 끝나면 아래 **B 항목 전체를 복사해서** 상대방에게 보내면 된다.

---

## B. 초대받은 분께 (이 아래를 그대로 전달)

안녕하세요. **다녀왔어요** 라는 개인용 맛집 기록 앱에 초대드립니다.

Instagram 에서 가보고 싶은 곳 릴스나 게시물을 보시면, **DM 으로 하나 보내주시기만 하면**
자동으로 목록에 저장됩니다. 따로 앱을 설치하실 필요는 없습니다.

처음 한 번만 아래 연결 절차가 필요합니다. 3분이면 끝납니다.

### 1단계 — 초대 수락 (PC 로 해주세요)

> **중요: 휴대폰 Instagram 앱에서는 이 메뉴가 안 보입니다.** 반드시 PC 브라우저로 해주세요.
> 앱에서 아무리 찾아도 없어서 헤매는 경우가 많습니다.

1. PC 브라우저에서 Instagram 에 **본인 계정으로 로그인**
2. 주소창에 아래 주소를 그대로 입력

   ```
   https://www.instagram.com/accounts/manage_access/
   ```

3. 상단 탭 중 **「테스터 초대」** 클릭
4. **Visitlog Collector-IG** 항목의 **수락** 버튼 클릭

수락이 끝나면 그 자리에 `Visitlog Collector-IG 에 회원님이 승인함 <날짜>` 라고 표시됩니다.
그 아래 **`삭제` 버튼은 연결을 끊는 버튼**이니 누르지 마세요.

**「테스터 초대」 탭이 안 보인다면** 아직 초대가 도착하지 않은 것입니다.
몇 분 기다렸다 새로고침해 보시고, 그래도 없으면 관리자에게 알려주세요.

### 2단계 — 릴스나 게시물 보내기

Instagram 에서 가보고 싶은 곳을 발견하면:

1. 릴스/게시물 하단의 **종이비행기(공유) 아이콘** 탭
2. 받는 사람으로 **`lswj.20000526`** (표시 이름: **ToGo**) 선택
3. 보내기

끝입니다. 잠시 후 목록에 자동으로 들어갑니다.

메모를 같이 적어 보내시면 그 내용도 함께 저장되니, "여기 파스타 맛있대" 같이
한 줄 남겨주시면 나중에 찾기 좋습니다.

### 되는 것 / 안 되는 것

| | |
|---|---|
| ✅ 릴스 공유 | 저장됩니다 |
| ✅ 게시물(피드) 공유 | 저장됩니다 |
| ✅ 공유 + 메모 | 메모까지 함께 저장됩니다 |
| ❌ 링크 없는 일반 대화 | 저장되지 않습니다 (그냥 대화로 남습니다) |
| ❌ 스토리 공유 | 저장되지 않습니다 |
| ❌ 사진·동영상 파일 첨부 | 저장되지 않습니다 |

### 저장되는 정보

투명하게 알려드립니다. 공유해주신 건에 대해 아래만 저장됩니다.

- 공유하신 게시물/릴스 **링크**
- 함께 보내신 **메시지 내용**
- 보낸 사람 **식별 번호** (Instagram 이 발급하는 숫자. 계정 이름·프로필이 아닙니다)
- 받은 **시각**

저장되지 않는 것: 프로필 정보, 팔로워 목록, 다른 사람과의 대화,
**링크가 없는 일반 대화 내용**.

### 그만두고 싶을 때

언제든 위 1단계와 같은 주소로 들어가

```
https://www.instagram.com/accounts/manage_access/
```

**Visitlog Collector-IG** 옆의 **`삭제`** 를 누르시면 연결이 끊어집니다.
이후 보내신 DM 은 저장되지 않습니다.

### 잘 안 될 때

| 증상 | 확인할 것 |
|---|---|
| 「테스터 초대」 탭이 없음 | PC 브라우저인지 확인. 휴대폰 앱에는 안 나옵니다 |
| 초대 항목이 없음 | 관리자가 아직 등록하지 않았거나 사용자명 오타. 관리자에게 문의 |
| 보냈는데 목록에 없음 | 릴스/게시물을 **공유**한 게 맞는지, 받는 사람이 `lswj.20000526` 인지 확인 |
| 텍스트만 보냄 | 의도된 동작입니다. 링크가 있는 공유만 저장합니다 |

## C. 관리자 확인 방법

상대방이 보냈는데 목록에 안 뜨면 Vercel 런타임 로그에서 원인을 볼 수 있다.

```
Vercel → visitlog → Logs → 검색: instagram-webhook
```

| 로그 | 의미 |
|---|---|
| 줄이 아예 없음 | Meta 가 발송하지 않음. 상대방의 테스터 수락이 안 된 상태 |
| `skipped: { plain_message }` | 링크 없는 텍스트. 정상 동작 |
| `droppedByAccountFilter > 0` | `INSTAGRAM_ACCOUNT_ID` 값 오류. `payloadAccountIds` 값으로 교체 |
| `matched: 1` + `inserted: 1` | 정상 저장됨 |

자세한 진단표는 [README](../README.md#dm을-보냈는데-수집함이-비어-있을-때) 참고.
